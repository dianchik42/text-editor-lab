# Регулярные выражения поиска подстрок

Шаблоны соответствуют реализации в `text_editor/regex_search.py`.

### Как читать запись регулярного выражения

Все шаблоны приведены точно в виде сырых строк Python, используемых в программе. Префикс `r` и внешние двойные кавычки относятся к синтаксису Python и не входят в само регулярное выражение. Кавычки не ищутся в тексте.

- `[...]` — класс: в данной позиции подходит один из перечисленных символов.
- Дефис между символами задаёт диапазон (`a-z`, `0-9`); в конце класса он означает буквальный дефис.
- `\` вводит специальное обозначение: например, `\w` или `\S`. Для поиска самого обратного слеша используется `\\`.
- `(?<!...)` — отрицательная проверка непосредственно слева; `(?!...)` — отрицательная проверка справа; `(?=...)` — положительная проверка справа. Эти проверки не включают проверяемые символы в совпадение.
- `?` после элемента означает 0 или 1 повторение; `*` — 0 или более; `{6}` — ровно 6; `{8,16}` — от 8 до 16; `{14,}` — не менее 14.
- Значение символа зависит от позиции: `?` внутри класса — обычный вопросительный знак, а `?` после `#` — квантификатор. Скобки внутри класса — буквальные символы, вне класса они оформляют проверки.

## HEX-цвет

Ищется отдельный код из шести шестнадцатеричных цифр. Допускается необязательный префикс #. Требование длины 6 относится к цифрам кода: `ABCDEF` содержит 6 символов, а найденная подстрока `#ABCDEF` — 7 с учётом префикса. Сокращённые коды и коды с альфа-каналом не поддерживаются.

```python
r"(?<![\w#])#?[0-9A-Fa-f]{6}(?!\w)"
```

**Пояснение каждого обозначения:**

- `r"..."` — сырая строка Python: обратные слеши передаются движку регулярных выражений.
- `(?<!...)` — отрицательная проверка символа слева, не включаемого в совпадение.
- `[\w#]` — один буквенно-цифровой символ Unicode, подчёркивание или #. Такая левая граница исключает код внутри слова и повторный префикс ##.
- `#?` — ноль или один символ #; `?` означает необязательность предыдущего элемента.
- `[0-9A-Fa-f]` — одна цифра 0–9 либо латинская буква A–F/a–f; квадратные скобки задают класс символов, дефис — диапазон.
- `{6}` — ровно шесть повторений предыдущего класса.
- `(?!\w)` — отрицательная проверка справа: следующий символ не должен быть буквой, цифрой или подчёркиванием. Это предотвращает извлечение первых шести цифр более длинного кода.

Должны находиться: `#A1b2C3`, `abcdef`, `000000`, `#FFFFFF`, код в строке `цвет: (#ABCDEF);`.

Не должны находиться: `#12345`, `#1234567`, `#12345678`, `#GG0000`, `wordABCDEF`, `ABCDEFword`, `##ABCDEF`.

## Юзернейм

Ищется целый юзернейм длиной от 8 до 16 символов включительно. Допустимы строчные латинские буквы, ASCII-цифры, дефис и подчёркивание. Условие задаёт разрешённый алфавит: наличие каждого из четырёх видов символов одновременно не требуется. Ограничения на первый символ в задании нет, поэтому юзернейм может начинаться с цифры, дефиса или подчёркивания.

```python
r"(?<![\w-])[a-z0-9_-]{8,16}(?![\w-])"
```

**Пояснение каждого обозначения:**

- `(?<![\w-])` — слева не должно быть символа слова Unicode или дефиса; не позволяет начинать совпадение внутри более длинного имени, включая имя с недопустимой заглавной или русской буквой.
- `[a-z0-9_-]` — один разрешённый символ: строчная латинская буква a–z, цифра 0–9, подчёркивание либо дефис. Дефис в конце класса обозначает сам себя.
- `{8,16}` — от 8 до 16 повторений включительно.
- `(?![\w-])` — справа не должно быть символа слова или дефиса; предотвращает совпадение с префиксом слишком длинного имени.
- `r`, квадратные скобки, `\w` и конструкции проверок имеют те же значения, что в задаче I. Проверки границ не входят в найденную подстроку.

Должны находиться: `abcd1234` (8), `user_name-01` (12), `abcdefghijklmnop` (16), `12345678` (8).

Не должны находиться: `abc1234` (7), `abcdefghijklmnopq` (17), `Abcd1234` (заглавная латинская буква), `Яabcdefgh` (русская буква), `abcdefghZ` (недопустимая буква в конце).

Пунктуация, не относящаяся к символам имени, служит разделителем при поиске в тексте. Например, `(abcd1234),` содержит допустимое совпадение `abcd1234`. Проверка полного произвольного значения отличается от поиска подстрок: `abc!defghijk` содержит отдельный допустимый фрагмент после !, но не является одним допустимым юзернеймом.

## Пароль

Для извлечения из произвольного текста принято соглашение: кандидат в пароль — целый непробельный фрагмент. Кандидаты разделяются пробелами, табуляцией или переводами строк. Пароли с пробелами не рассматриваются. Вводить примеры удобно по одному на строке, без кавычек и поясняющей пунктуации внутри кандидата.

Требуется не менее 14 символов, хотя бы одна буква А–Я/Ё, одна а–я/ё, цифра 0–9 и хотя бы один специальный символ. Регистр учитывается; латинские A/a не заменяют русские А/а. Верхнего предела длины нет.

```python
r"(?<!\S)(?=\S*[А-ЯЁ])(?=\S*[а-яё])(?=\S*[0-9])(?=\S*[()#?!|/@$%\\^&*_-])\S{14,}(?!\S)"
```

**Пояснение каждого обозначения:**

- `\S` — любой непробельный символ (противоположность `\s`).
- `(?<!\S)` — слева начало текста или пробельный разделитель, то есть начало целого кандидата.
- `(?=...)` — положительная проверка вперёд; проверяет условие, но не потребляет символы.
- `*` — ноль или больше повторений. `\S*` позволяет искать обязательный символ в любой позиции текущего кандидата, не переходя через пробел или перевод строки.
- `(?=\S*[А-ЯЁ])` — в кандидате есть заглавная русская буква. Ё указана отдельно, поскольку не входит в диапазон А–Я.
- `(?=\S*[а-яё])` — в кандидате есть строчная русская буква; ё указана отдельно.
- `(?=\S*[0-9])` — есть хотя бы одна ASCII-цифра. Использование `[0-9]` вместо `\d` явно исключает цифры других систем письма.
- `(?=\S*[()#?!|/@$%\\^&*_-])` — есть специальный символ из класса. Список реализован буквально: круглые скобки, #, ?, !, вертикальная черта, /, @, $, %, обратная косая черта, ^, &, *, дефис и подчёркивание. Повторяющийся / из условия достаточно указать один раз.
- Внутри класса скобки, `?`, `!`, вертикальная черта, `/`, `@`, `$`, `%`, `&`, `*`, `_` обозначают сами себя; `^` находится не в начале и не означает отрицание. `\\` в сырой строке РВ означает один буквальный обратный слеш. Дефис в конце класса — буквальный дефис.
- `\S{14,}` — потребить не менее 14 непробельных символов, без верхнего ограничения.
- `(?!\S)` — справа пробел или конец текста: нельзя возвращать лишь часть кандидата.

Допускаются другие непробельные символы, в том числе латинские буквы: условие задаёт обязательные категории, а не запрещает остальные символы. Спецсимвол вне списка может присутствовать, но не заменяет обязательный символ из списка.

Должны находиться:

```text
Ая1!xxxxxxxxxx
Ёё1_xxxxxxxxxx
ПарольНадежный1!
```

Первые два примера имеют длину 14, третий — 16.

Не должны находиться:

| Пример | Причина |
| --- | --- |
| `Ая1!xxxxxxxxx` | 13 символов |
| `АА1!xxxxxxxxxx` | Нет строчной русской буквы |
| `яя1!xxxxxxxxxx` | Нет заглавной русской буквы |
| `Аяa!xxxxxxxxxx` | Нет цифры |
| `Ая1axxxxxxxxxx` | Нет специального символа из списка |
| `Aa1!xxxxxxxxxx` | Только латинские буквы |
| `Ая١!xxxxxxxxxx` | Арабская цифра вместо цифры 0–9 |
| `Ая1! xxx xxxxxxx` | Разделён на три слишком коротких кандидата |

## Алгоритм и флаги

Шаблоны компилируются один раз через `re.compile`. Вызов `finditer` возвращает все неперекрывающиеся совпадения. Для каждого берутся исходный фрагмент, индекс начала и длина. По предварительно составленному списку начал строк вычисляются номер строки и номер символа. Результаты идут в порядке исходного текста.

Дополнительные флаги не используются. `IGNORECASE` нарушил бы требования к регистру юзернейма и пароля; оба регистра HEX перечислены явно. `MULTILINE` не нужен: шаблоны не используют ^ и $ как якоря строк. Флага Global в Python нет, все совпадения выдаёт `finditer`. Unicode-режим Python по умолчанию используется для надёжных границ `\w` и пробельных символов `\S`.
